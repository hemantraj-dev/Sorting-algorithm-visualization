## 📌 About The Project

SortLab is an interactive web-based Sorting Algorithm Visualizer
that demonstrates how different sorting algorithms work through
real-time animations.

The main purpose of this project is to help students, beginners,
and developers understand sorting algorithms visually rather
than only reading theoretical explanations.

Users can generate arrays, select sorting algorithms, control
animation speed, observe comparisons and swaps, and understand
algorithm complexity.

## 🧠 Implemented Sorting Algorithms

SortLab includes 13 sorting algorithms:

| No. | Algorithm | Average Time Complexity |
|---|---|---|
| 1 | Bubble Sort | O(n²) |
| 2 | Selection Sort | O(n²) |
| 3 | Insertion Sort | O(n²) |
| 4 | Merge Sort | O(n log n) |
| 5 | Quick Sort | O(n log n) |
| 6 | Heap Sort | O(n log n) |
| 7 | Shell Sort | Depends on gap sequence |
| 8 | Counting Sort | O(n + k) |
| 9 | Radix Sort | O(d(n + b)) |
| 10 | Cocktail Shaker Sort | O(n²) |
| 11 | Comb Sort | O(n²) |
| 12 | Gnome Sort | O(n²) |
| 13 | Bucket Sort | O(n + k) average |

## 🎮 How To Use

1. Open the SortLab website.
2. Select your preferred sorting algorithm.
3. Generate a random array or enter custom values.
4. Adjust the array size.
5. Set your preferred animation speed.
6. Click the Start button.
7. Observe the sorting process.
8. Monitor comparisons, swaps, and execution time.
9. Use Pause, Step Forward, and Reset to control execution.
10. Explore algorithm complexity and pseudocode.

## 🚀 Installation & Setup

### Run Locally

1. Clone this repository:

```bash
git clone https://github.com/hemantraj-dev/sorting-visualizer.git
```

2. Open the project folder:

```bash
cd sorting-visualizer
```

3. Open `index.html` in your browser.

No additional dependencies or installations are required.

---

## 🌍 Deployment Using GitHub Pages

Follow these steps to deploy SortLab:

1. Create a GitHub repository.
2. Upload `index.html` and `README.md`.
3. Navigate to Settings.
4. Select Pages.
5. Under Build and Deployment, choose Deploy from a branch.
6. Select the `main` branch.
7. Select the `/ (root)` folder.
8. Click Save.
9. Wait for GitHub Pages to publish your website.

Your website will be available at:

```text
https://hemantraj-dev.github.io/sorting-visualizer/
```

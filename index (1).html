Algorithm overview

Bubble Sort repeatedly compares adjacent values and swaps them when they are in the wrong order.

ComplexityBestAverageWorst
TimeO(n)O(n²)O(n²)

How it works

The bars show the current array state. Orange bars are being compared; pink bars are being moved or swapped; green bars are in their final sorted positions.

for each pass: compare adjacent values swap if left value is greater mark the final value as sorted
